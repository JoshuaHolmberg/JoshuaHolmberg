## Projects

### [NBA Live Win Probability Model](https://github.com/JoshuaHolmberg/NBAData-Pull)
Real-time Bayesian win probability model for NBA games. Ingests play-by-play data from the NBA API across 4 seasons (2022–2026, regular season + playoffs), reconstructs full game-state timelines, and engineers a rich feature set for in-game win probability estimation.

**Pipeline complete** — data collection, game-state reconstruction, and feature engineering across ~5,000+ games. Model training in progress.

**Features:** score differential · time remaining · possession · foul tracking · 5/10-play momentum windows · team rolling ratings (last 10/20/season) · rest/fatigue indicators (back-to-back, 3-in-4) · differential features across all windows

`Python` `pandas` `scikit-learn` `NBA API`

### [Serial Dependence in Dermatological Judgment](https://github.com/JoshuaHolmberg/SD-MLModel)
ML analysis from the **Whitney Lab for Perception and Action, UC Berkeley**. Investigates whether participants show serial dependence — systematically failing to update their classification when the stimulus category changes — when classifying skin lesions as malignant or benign.

Multi-modal feature set drawn from eye tracking (pupil dilation), mouse tracking, and behavioral responses. Three classifiers compared with stratified 5-fold cross-validation and permutation feature importance.

`Python` `scikit-learn` `pandas` `scipy` `seaborn`
